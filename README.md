# User-details-app
📝 User Details Form (React + Spring Boot + MySQL)

A full-stack **User Management Form** application built with:
- **Frontend**: React (with form handling and preview for file uploads)
- **Backend**: Spring Boot (REST API with file handling)
- **Database**: MySQL (for storing user details)

This project allows users to:
- Fill personal details in a form  
- Upload files (photo, document)  
- View all users in a list  
- Edit or delete existing users  



## 🚀 Features
- Create a new user with details (name, DOB, gender, languages, etc.)
- Upload and preview photo/document before submitting
- Store uploaded file names in the database (not full random IDs)
- Update existing users without creating duplicates
- Delete users from the database
- Responsive frontend with React
